# Android 签名密钥（自用）

`deepin-gomoku.keystore.b64` 是 base64 编码的 PKCS12 密钥库，CI 构建后用它签名 APK。

- alias：`deepin-gomoku`
- 口令：`gomoku-signing-2024`
- 证书 SHA-256：`9C:73:85:0D:82:93:77:A9:5F:14:37:76:26:C7:B4:A8:B7:D1:52:83:20:5B:A7:94:BB:97:48:3A:9F:91:DB:7C`
- 有效期：10000 天

## 为什么把密钥放进仓库

GitHub Actions 里拿不到本地密钥文件，而签名密钥必须在每次构建中保持一致——否则新包和已安装的旧包签名不同，只能卸载重装。这个仓库是个人自用 fork，不发布到应用商店，因此密钥随仓库保存。

## 注意事项

- 密钥公开意味着别人也能用同一密钥签名 APK；仅适用于自用分发。
- **不要更换密钥**：换掉之后已安装的旧版本无法覆盖升级，必须先卸载。
- 想要更稳妥的做法：把 base64 内容存进仓库的 Actions Secret（例如 `KEYSTORE_B64`），再把工作流里的解码步骤改成读取该 secret。
